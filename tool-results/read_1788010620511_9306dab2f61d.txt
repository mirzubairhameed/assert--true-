  1283→**What's happening here:**
  1284→
  1285→**Visual identity** — I picked a warm "programmer's notebook" aesthetic: Fraunces serif for editorial headlines, JetBrains Mono for the typewriter and code, Space Grotesk for body. The default dark theme uses honey-amber on warm-black (not blue!), light is paper-cream with burnt sienna, and cyber goes full phosphor-green-on-black with CRT scanlines as a `body::before`.
  1286→
  1287→**Three-state theme toggle** — Sun/moon/terminal icons in a segmented pill. Clicking adds a `theme-anim` class that applies a 0.6s transition to every element's color/background/border, then removes itself so it doesn't slow down scroll animations. Theme persists in localStorage; press **T** to cycle.
  1288→
  1289→**Typewriter greeting** — Cycles through 5 programmer-flavored strings (`"hello, traveler."`, hex strings, `console.log`…) with realistic per-character jitter and a block cursor.
  1290→
  1291→**Hover-raise cards** — Each article card lifts 8px, reveals an animated top accent bar, glows in the bottom-right corner, big numeral "01/02/03" brightens, title shifts to accent color, arrow slides right.
  1292→
  1293→**Copy-flash buttons** — Each code window has a copy button. On click: full flash overlay sweeps across the button, label swaps to "copied" with a checkmark, then reverts after 1.8s. Uses Clipboard API with a `textarea` fallback.
  1294→
  1295→**Reading progress bar** — 3px gradient bar at the very top, glow shadow, updates on scroll.
  1296→
  1297→**Live GitHub counters** — Fetches `tailwindlabs/tailwindcss` from the GitHub API, animates the numbers counting up from 0 with a cubic ease-out. Falls back to plausible static numbers on rate-limit. Every ~9s there's a 35% chance the star count ticks up by 1 with a flash animation — to simulate live activity.
  1298→
  1299→**Dynamic layers** — Drifting blurred blobs, mouse-following radial glow in the hero, parallaxing grid background, marquee tech-stack ticker, scroll-reveal observer, animated stat dots, and the CRT scanline overlay in cyber mode.
